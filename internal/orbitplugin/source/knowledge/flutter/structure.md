# Flutter 프로젝트 구조

- Dart SDK 버전은 `pubspec.yaml`의 `environment`에서 확인하고, 그 버전이 허용하는 문법(널 안전성, 레코드·패턴 매칭 등)만 쓴다.
- `lib/`가 기능 우선 구조(`features/<기능명>/`)이면 새 화면을 그 기능 디렉토리 아래에 만들고, 여러 기능이 함께 쓰는 것만 공용 디렉토리(`shared`, `core` 등)로 올린다.
- 상태 관리나 HTTP 클라이언트 라이브러리가 둘 이상 들어 있으면 임의로 고르지 않는다. 손대는 기능이 이미 쓰는 쪽을 따른다. 그 기능에 선례가 없으면 어느 쪽을 쓸지 결정을 요청한다. 두 방식을 한 화면에 섞지 않는다.
