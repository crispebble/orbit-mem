# Vite(`scripts.dev`가 `vite`)

- 전부 클라이언트 렌더링이다. 서버 컴포넌트 개념이 없다.
- 라우팅은 보통 `react-router-dom`이다. 파일 기반 라우팅이 아니라 라우트를 코드로 선언한다. `package.json`에서 확인한다.
- 전역 상태(`zustand` 등)와 아이콘(`lucide-react` 등) 라이브러리는 프로젝트마다 다르다. `package.json`에서 확인하고, 있으면 기존 패턴을 따른다. 새 라이브러리를 추가하지 않는다.
- 빌드 스크립트가 `tsc --noEmit && vite build`처럼 타입 체크를 포함하면 **타입 오류가 빌드 실패다.** 구현 후 타입 체크를 반드시 통과시킨다.
- 자격증명과 API 키를 클라이언트 코드에 넣지 않는다. Vite는 `VITE_` 접두어 환경변수가 번들에 그대로 들어간다.
