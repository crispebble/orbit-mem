# Pull Request Rules (기본값)

이 문서는 레포에 자체 PR convention이 없을 때 적용하는 기본 규칙이다. 레포에 규칙이 있으면 그것을 우선한다.

커밋 관련 규칙은 `git-commit` 스킬에 있다.

## 제목과 브랜치

- PR 제목은 `[type] 한 줄 요약` 형식을 사용한다.
- PR 제목의 예시는 `[feat] 유저 팔로우 API 구현`, `[fix] 피드 무한스크롤 중복 로딩 버그 수정`, `[refactor] InsightService 조회 로직 레이어 분리`, `[chore] QueryDSL 의존성 추가`이다.
- PR `type`은 다음 값 중에서 선택한다.

| Type | 설명 |
| --- | --- |
| `feat` | 새로운 기능 추가 |
| `fix` | 버그 수정 |
| `refactor` | 기능 변경 없는 코드 구조 개선 |
| `perf` | 성능 개선. 쿼리 최적화, 캐시 도입 등 |
| `test` | 테스트 코드 추가 또는 수정 |
| `docs` | 문서, 주석 변경 |
| `chore` | 빌드, 의존성, 설정 변경 |
| `style` | 포맷팅, 코드 스타일. 로직 변경 없음 |
| `hotfix` | 운영 긴급 패치 |

- `hotfix`는 배포 성격을 나타내는 PR 전용 값이며 커밋 type으로는 쓰지 않는다.
- 브랜치명은 `type/task-summary-kebab-case` 형식을 사용하고 영문으로 작성한다. 예: `feat/user-follow-api`.
- 기본 브랜치 전략은 `main`을 배포 브랜치, `develop`을 통합 브랜치로 본다. 프로젝트별 전략이 있으면 프로젝트 규칙을 우선한다.

## PR 크기와 본문

- 하나의 PR은 하나의 관심사만 다룬다. 기능 추가와 리팩터링을 불필요하게 섞지 않는다.
- 가능하면 변경 파일 10개 이하, 변경 라인 400줄 이하를 권장한다.
- 불가피하게 PR이 커지면 PR 본문에 변경 맥락과 리뷰 포인트를 충분히 작성한다.
- PR 본문에는 다음 항목을 포함한다.
  - 개요: 이 PR이 왜 필요한지, 어떤 문제를 해결하는지 한 문단으로 작성한다.
  - 변경 사항: 주요 변경을 목록으로 정리한다.
  - 구현 상세 또는 기술적 결정: 비자명한 설계 결정, 트레이드오프, 고려했지만 선택하지 않은 대안을 작성한다.
  - 연관 이슈: `closes #이슈번호`, `ref #이슈번호` 형식으로 작성한다.
  - 체크리스트: 셀프 리뷰, 테스트 작성 또는 기존 테스트 통과, API 변경 시 문서 업데이트, 환경변수나 설정값 변경 공유 여부를 확인한다.
  - 스크린샷 또는 테스트 결과: UI, API 응답, 로그, 성능 측정 등 리뷰에 도움이 되는 자료가 있으면 첨부한다.

## 라벨

- PR 라벨은 필요할 때 다음 의미로 사용한다.
  - `needs-review`: 리뷰 요청 중
  - `in-progress`: 아직 작업 중인 Draft PR
  - `blocked`: 다른 PR 또는 이슈 해결 대기 중
  - `hotfix`: 긴급 배포 필요
  - `breaking-change`: 하위 호환이 깨지는 변경

## 리뷰

- 리뷰 코멘트는 의도를 명확히 하기 위해 `[blocker]`, `[suggestion]`, `[question]`, `[nit]`, `[praise]` 접두어를 사용할 수 있다.
- `[blocker]`는 머지 전 반드시 수정해야 하는 문제에만 사용한다.
- `[suggestion]`은 선택 가능한 개선 제안에 사용한다.
- `[question]`은 이해를 위한 질문에 사용한다.
- `[nit]`은 사소한 지적에 사용하며 머지 여부는 작성자가 판단한다.
- `[praise]`는 긍정 피드백에 사용한다.
- 작성자는 Draft PR을 먼저 열어 방향을 공유하고, 준비되면 `Ready for Review`로 전환할 수 있다.
- 리뷰 반영 후에는 관련 스레드를 resolve 처리하고 필요하면 re-request review를 요청한다.
- 리뷰어는 코드 세부보다 설계와 의도를 먼저 파악하고, `[blocker]` 외 코멘트는 작성자에게 결정권이 있음을 전제로 한다.
